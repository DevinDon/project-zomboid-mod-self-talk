# Project Zomboid Mod Self-Talk

## 简介

Self-Talk 是一款《Project Zomboid》模组，让角色在情绪状态变化时触发自言自语台词，增强游戏沉浸感。模组支持中英双语，并采用了优化的目录结构，确保与其他模组兼容共存。

## 功能

- 🧠 **情绪变化台词** — 角色情绪状态变化时触发对应的自言自语
- 🌐 **中英双语** — 内置中文与英文翻译，支持自动切换
- 🧩 **模块化架构** — 清晰的文件组织结构，便于扩展和维护
- 🔧 **可配置选项** — 支持通过模组选项自定义行为
